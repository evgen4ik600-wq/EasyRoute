# 🚀 EasyRoute for OpenWrt

**EasyRoute** — простой интерфейс выборочной маршрутизации приложений, сайтов и домашних устройств через **AmneziaWG** на OpenWrt.

> **Выбираешь приложение → выбираешь VPN → работаешь. 🚀**

## 🤔 Какую проблему решает

Обычная задача звучит просто: **YouTube, Telegram, ChatGPT и Instagram отправлять через VPN, а банки, российские сайты, игры и остальной интернет — напрямую.**

В стандартном OpenWrt такая настройка быстро превращается в работу с AmneziaWG, firewall4/nftables, fwmark, routing tables, ip rule, CIDR, dnsmasq-full и nftset.

EasyRoute прячет эту сложность за понятным LuCI-интерфейсом.

- 📺 YouTube → 🛡️ VPN
- ✈️ Telegram → 🛡️ VPN
- 🤖 ChatGPT → 🛡️ VPN
- 🏦 остальной интернет → 🌍 WAN

## ✨ Что умеет

- 🧩 готовый каталог популярных сервисов;
- 🌐 автоматическое добавление доменов и IPv4/CIDR;
- 🔄 автоматическое обновление URL-списков;
- 🛡️ работа с системными AmneziaWG-интерфейсами OpenWrt;
- 📱 обнаружение устройств в локальной сети;
- 🟢 включение/выключение маршрутов одним переключателем;
- 🩺 самодиагностика Internet/VPN/firewall/DNS/routing;
- 🔐 опциональный DNS-over-TLS через Stubby с AdGuard/Cloudflare/Google без отключения IPv6 и без переписывания WAN DNS;
- 🔥 проверка firewall-конфигурации перед применением;
- ↩️ rollback при ошибке;
- ⚙️ технические параметры спрятаны от обычного пользователя.

## 🌐 Защищённый DNS

EasyRoute 1.1.25 умеет по желанию включить DNS-over-TLS через Stubby.

Схема:

    Клиент → dnsmasq → Stubby :5453 → DoT :853 → выбранный DNS

Важно: dnsmasq остаётся перед Stubby, поэтому доменная маршрутизация через nftset продолжает работать. EasyRoute не меняет WAN/PPPoE DNS-параметры и не отключает IPv6. Если Stubby уже настроен вручную вне EasyRoute, автоматическая настройка блокируется во избежание конфликта.

## 🧠 Архитектура

    Устройство
        │
        ▼
      OpenWrt
        │
        ├── обычный трафик ───────────► WAN
        │
        └── выбранные сервисы
                    │
                    ▼
              nftables / fwmark
                    │
                    ▼
               routing table
                    │
                    ▼
               AmneziaWG VPN

EasyRoute **не реализует собственный VPN-протокол**. Он использует обычные системные интерфейсы AmneziaWG, поэтому VPN не оказывается заперт внутри приложения.

## 📦 Требования

- OpenWrt 24.10.x / 25.12.x;
- LuCI;
- firewall4 / nftables;
- AmneziaWG;
- dnsmasq с nftset.

Совместимость AmneziaWG зависит от версии OpenWrt, ядра и архитектуры конкретного роутера.

## 🚀 Установка

Подключитесь к OpenWrt по SSH под root:

    wget -qO- "https://raw.githubusercontent.com/evgen4ik600-wq/EasyRoute/main/install.sh?$(date +%s)" | sh

После установки откройте:

**LuCI → Сеть → 🚀 EasyRoute**

## 🧑‍🦳 Принцип интерфейса

EasyRoute проектируется так, чтобы для обычной настройки человеку не требовалось знать, что такое CIDR, fwmark, nftables, ip rule, routing table или nftset.

Пользователь должен понимать только:

1. 🛡️ какой VPN использовать;
2. 🧩 какие приложения/сайты отправлять через него.

## 🛡️ Безопасность

EasyRoute не должен:

- переписывать произвольные сетевые интерфейсы;
- автоматически захватывать любой найденный AWG;
- удалять AmneziaWG при удалении EasyRoute;
- удалять /etc/config/network;
- заменять весь пользовательский firewall;
- применять сгенерированный firewall без предварительной проверки.

EasyRoute использует собственные nftables-файлы и namespaced-объекты.

## 🧪 Проверки

GitHub Actions проверяет shell, JSON, LuCI JavaScript, установщик и основные архитектурные инварианты. CI дополняет, но не заменяет тестирование сетевых изменений на реальном OpenWrt-роутере.

## ❤️ Зачем EasyRoute

OpenWrt даёт огромную свободу, но выборочная VPN-маршрутизация обычно требует знаний сетевого администратора.

**EasyRoute оставляет мощность OpenWrt, но делает повседневное управление VPN понятным обычному человеку.**
